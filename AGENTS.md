# Instrucciones para agentes

## Idioma

- Idioma del repositorio: español.
- Todo lo que se escribe en el repositorio va en español: el código (nombres y comentarios), la documentación, los textos de la extensión, los tests, los scripts, las notas de release y los mensajes de commit. Se conservan los nombres definidos afuera, como las clases del sitio de Promiedos, y la clave de almacenamiento `promiedos-focus:hidden-leagues:v1`, de la que dependen las preferencias guardadas.
- La conversación sigue el idioma del usuario.

## Git

- Escribí todos los mensajes de commit en español.
- No hagas commits sin autorización explícita del usuario para esa acción.
- No hagas push sin autorización explícita del usuario para esa acción. La autorización para hacer un commit no implica autorización para hacer push.
